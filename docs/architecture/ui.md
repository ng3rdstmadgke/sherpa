# 画面の骨組み

[overview.md](overview.md) から分けた、画面の全体の構成。ファイルメニューの中身は [files.md](files.md) と [search.md](search.md)、Git メニューの中身は [git.md](git.md) にある。

```
┌ sherpa ─ [Projects] [● webapp ×] [● webapp / 33_new_region ×] [● infra ×] [⚙ 設定 ×] [+] ─ ☾ ⚙ ┐
├ [⎇ worktree ▼] [比較: main +未コミット ▼] [📄 SPEC: agent-tasks/…/*  4 件] (i)                  ⟳• ┤
│📄│ /Contents\ /File\    │ [spec.md ×][regions.ts ×]  ◫ ⊟ × │ [overview.md (main) ×]    ◫ ⊟ × │
│⎇ │ [🔍 検索  Aa .*]     │ regions.ts                         │ overview.md                      │
│  │ ▾ SPEC (4)           │ [Unified|Split] [差分|全体]        │ [プレビュー|ソース] [差分|全体]  │
│  │ ▾ EXPLORER           │  (エディタグループ 1)              │  (エディタグループ 2)            │
└──┴──────────────────────┴────────────────────────────────────┴──────────────────────────────────┘
```

## 1. 一番上のタブ (プロジェクトタブ)

- 1 つのタブが「プロジェクト + worktree」に対応する。同じプロジェクトを複数のタブで開ける
- ラベルは、main worktree なら `プロジェクト名`、それ以外なら `プロジェクト名 / worktree 名`
- `+` メニューにはプロジェクトごとに worktree の一覧が並び、選んだ worktree を新しいタブで開く。同じ組がすでに開いていれば、そのタブに移る。見つからない worktree は選べない
- タブの中で worktree を切り替えると、ラベルも切り替わる
- × か中クリックで閉じる。閉じたタブの保存状態 (`ws:<タブの id>`) も消す
- プロジェクトのタブの後ろに、全体の設定のタブが並ぶ
- 右上に、ライト / ダークの切り替え (☾) と、全体の設定 (⚙) のボタンを置く
  - テーマは保存する。サーバーが `<html>` に `dark` を付けて返すので、読み込み直後にライトで一瞬表示されることはない
  - テーマを切り替えると、表示中の mermaid の図もそのテーマで描き直す
- 登録を解除したプロジェクトのタブは出さない
- git が見つからないときは、タブの下に帯で知らせる

## 2. ホーム (Projects)

- 登録済みのプロジェクトを、登録した順にカードで表示する (並べ替えはしない)
- カードには worktree ごとに、ブランチ、プロジェクトの直下からのパス、ahead / behind、未コミットのファイル数を出す
  - ahead / behind は、プロジェクトの既定の比較対象に対する値 ([git.md](git.md) §5)
  - ブランチにない HEAD は `(detached) <短いハッシュ>`。見つからない worktree は薄く出し、開けない
- worktree の行をクリックすると、その worktree をタブで開く
- カードの「…」メニュー: 「編集」「登録を解除」([projects.md](projects.md))
- 登録: 「プロジェクトを登録」ボタン ([projects.md](projects.md))
- プロジェクトがないときは、登録を促す案内を出す

## 3. 全体の設定

- 右上の歯車のボタンで、一番上のタブの並びに「⚙ 設定」タブを開く (専用のページ)。すべてのプロジェクトに適用する
  - 設定タブは 1 つだけ。開いていればそこへ移る。× か中クリックで閉じる。開いているかどうかは保存する
  - 左に項目の一覧 (グループ分け)、右に内容を並べる。項目の一覧をクリックすると、その項目までスクロールする
  - 他の画面から項目を指定して開いたときは、その項目までスクロールして枠で強調する
- 変更は自動で保存する (保存ボタンはない)。入力が止まってから 600 ms で、変わった項目だけを保存する。下の帯に「保存中…」「保存しました」やエラーを出す
- 項目
  - 表示 › フォントサイズ: ソースコード (ファイルの表示と差分) と Markdown のプレビューの文字の大きさ。10〜24 px の整数 (既定はコード 13 px、Markdown 14 px)。範囲の外や数でない値のあいだは保存せず、欄の下に理由を出す。欄の横に、その大きさの見本を出す。「既定に戻す」で既定値を入れる
  - 表示・検索 › 除外パターン ([files.md](files.md) §3)。「初期値に戻す」で初期値を入れる
- フォントサイズは CSS の変数 (`--sherpa-code-font-size` / `--sherpa-markdown-font-size`) で効かせる。サーバーが `<html>` に付けて返すので、読み込み直後から効く。保存すると、開いているタブにもすぐ効く

## 4. worktree バー

一番上のタブの下に置く。

```
[⎇ 33_new_region ▼] [比較: main +未コミット ▼] [📄 SPEC: agent-tasks/226_add_gateway/*   2 件] (i)   ⟳•
```

- **worktree の選択**: タブの中で worktree を切り替える。一覧には各 worktree の変更の数、↑↓、ブランチ、最新のコミットを出す
- **比較対象の選択** (§4.1)
- **SPEC 欄**: SPEC に出すドキュメントの場所を入力する ([files.md](files.md) §2)
  - カンマ区切りで複数指定できる。末尾の `/*` と、ワイルドカードのないディレクトリの指定は、その下の階層すべてを対象にする
  - spec の場所はブランチ名から決まるとは限らないため、worktree ごとに手で指定して保存する
  - `Enter` かフォーカスが外れたときに確定し、`Esc` で入力前に戻す。右に、見つかった `.md` の件数を出す
- **(i) 詳細**: ポップオーバーで、ブランチ名・ディレクトリ・コンテナ内のパス (読み替えている場合)・比較対象との差 (↑↓)・最新のコミットを出す。ブランチ名とパスにはコピーボタンを付ける。下部に「プロジェクトの設定」
- 右端に再読み込みボタン。自動更新の状態を点で示す ([live-reload.md](live-reload.md))
- タブの worktree が見つからないときは、バーの代わりに「worktree が見つかりません」と、main worktree に切り替えるボタンを出す

### 4.1 比較対象

- 「比較: main ▼」のプルダウンで、タブごとに比較対象のブランチを選ぶ。選んだ値は保存する
  - 検索できる一覧から選ぶ。ローカルとリモートに分けて並べ、最終コミットの新しい順にする
  - 「未コミットの変更を含む」(既定 ON)。ON なら比較範囲は `<branch>...作業ツリー`、OFF なら `<branch>...HEAD`
- 新しく開いたタブの比較対象は、プロジェクトの既定の比較対象 ([git.md](git.md) §5)。どれもなければ「未選択」になり、選ぶまで COMPARE などは空
- 選んだブランチが見つからない・エラーのときは、プルダウンを赤くする
- 比較対象はタブ全体の設定で、Git メニューの COMPARE と HISTORY、エクスプローラの「変更のみ」と記号、ファイルのタブの「差分」、(i) の ↑↓ が参照する

## 5. メニュー (左端のアイコン列)

| メニュー | サイドパネル | 中央 |
| --- | --- | --- |
| ファイル (`Ctrl+Shift+E`) | 検索 / SPEC / エクスプローラ | ファイル用のエディタ領域 |
| Git 差分 (`Ctrl+Shift+G`) | 未コミットの差分 / COMPARE / HISTORY | Git 用のエディタ領域 |

- 中央のエディタ領域 (タブと分割の状態) は、メニューごとに独立して持つ。切り替えても、それぞれのタブ・分割・スクロール位置は残る
- Git のアイコンのバッジには、未コミットのファイル数を出す
- サイドパネルのセクションは、境界線のドラッグで縦幅を変えられ、見出しのクリックで折りたためる。配分と折りたたみは保存する (すべてのタブで共通)

## 6. エディタ領域 (画面分割)

- VS Code のエディタグループに相当する。グループ (タブの束) を左右・上下に、入れ子で分割できる
- ドラッグ & ドロップ
  - ドラッグできるもの: タブ、SPEC・エクスプローラのファイル、Git メニューの変更ファイルとコミット
  - グループの本文の端 (上下左右の 25%) にドロップすると、その方向に分割して新しいグループで開く。中央かタブバーにドロップすると、そのグループに移る
  - ドラッグ中は、ドロップ先の領域をハイライト表示する
- タブバーの右端に「右に分割」「下に分割」「グループを閉じる」のボタン
- 最後のタブを閉じたグループは自動で消える (最後の 1 グループは残す)
- 分割の境界線はドラッグしてサイズを変えられる
- タブの種類は 3 つ: ファイル、差分 (`regions.ts (未コミット)` / `regions.ts (main)`)、コミット (短いハッシュ)
- 新しく開いたタブ (プロジェクトタブ) のエディタ領域は空で始まる

### 6.1 グループ内検索 (Ctrl+F)

- `Ctrl+F` で、選択中のグループの右上に検索バーを出す
  - 範囲は選択中のグループで表示しているタブの本文だけ。対象はコード、Markdown のプレビュー、差分、コミットの詳細。差分の行番号と `+` / `-`、mermaid の図の中の文字は対象外
- `Enter` で次へ、`Shift+Enter` で前へ、`Esc` で閉じる。大文字小文字の区別を切り替えられる。件数 (`3/12`) を出す
- 文字列を選択してから押すと、それを検索語にする。開いたままタブを切り替えると、切り替えた先で検索し直す
- 検索欄にフォーカスがある状態でもう一度 `Ctrl+F` を押すと、ブラウザ標準の検索を開く
- 強調には CSS Custom Highlight API を使う (DOM を書き換えない)

## 7. パス入力のサジェスト

| 入力欄 | 候補 | 複数指定 | ディレクトリの直後に出す候補 |
| --- | --- | --- | --- |
| 登録の「ディレクトリ」、マッピングの「ホスト」 | ホームの下のディレクトリ (git リポジトリに「git」、登録済みに「登録済み」の印) | - | - |
| プロジェクトの「表示しないパス」 | main worktree の中のファイルとディレクトリ (`.gitignore` の対象に「gitignore」の印) | 1 行に 1 つ | `dir/**` |
| worktree バーの SPEC 欄 | その worktree の中 (同上) | カンマ区切り | `dir/*` |
| 検索の「対象」「対象外」 | その worktree の中 (同上) | カンマ区切り | - |

- 入力中のパスの最後の `/` までをディレクトリとし、その中身のうち続く文字で始まるものを出す (シェルの補完と同じ)。ディレクトリを選ぶと、続けてその中身を出す
- 複数指定の欄では、カーソルのある項目だけを補完する
- `Tab`: 選択中 (なければ先頭) の候補で補完。`↑` `↓`: 候補を選ぶ。`Esc`: 閉じる。`Enter` は `↑` `↓` で選んでいるときだけ補完に使う
- `*` を含む項目では候補を出さない
- 候補はサーバーから取り、ディレクトリごとに 30 秒キャッシュする (API は [api.md](api.md))

## 8. 画面の状態の保存と復元

- 保存するもの (キー): 開いているタブ (`instances`)、選択中のタブ (`activeId`)、設定タブ (`settingsOpen`)、テーマ (`theme`)、タブごとのメニュー・エディタのレイアウト・比較対象 (`ws:<タブの id>`)、サイドパネルの配分 (`files-panel-layout` / `git-panel-layout`)
- SPEC 欄の入力は UI の状態ではなく worktree のデータとして保存する ([storage.md](storage.md))
- 仕組み (`web/src/lib/persist.ts`)
  - `usePersistentState` は最初の描画で値を同期的に読む。`page.tsx` がサーバーで `ui_state` を全部読んで渡し、persist.ts がメモリに持つ
  - 変更は 500 ms まとめてから `PUT /api/ui-state` で書く。ページを閉じるときは `fetch(..., { keepalive: true })` で残りを送る
  - タブを閉じたときは `deletePrefixes` で `ws:<id>` を消す
- ブラウザのタブを 2 つ開いたときは、後に書いた方が残る
- 保存しないもの: エクスプローラの絞り込み (「変更のみ」など) と開閉、検索欄の入力
